# User Directory App

A simple React-based user directory that supports:

- Live Search  
- Sort by First Name / Email  
- Filter by Email Domain  
- Pagination  
- Loading Spinner  
- Local users.json API  

This project demonstrates how to implement search, filtering, sorting, and pagination in React using a local JSON file.

---

## 🚀 How to Run

1. Download or clone the project  
2. Install dependencies:npm install
3. and run it with npm start
